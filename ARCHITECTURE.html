Lead Status Lifecycle
new → enriched → email_generated → emailed → followup_1_sent → followup_2_sent → replied

bounced can occur at any send stage    unsubscribed opt-out via email
Background Jobs (APScheduler)
Reply Check
Every 5 minutes
Poll all Gmail inboxes, match replies to sent emails via thread ID, classify responses, detect bounces.
Follow-Up Check
Every 1 hour
Find leads emailed >2 days ago without reply, generate follow-up 1. Leads with FU-1 sent >3 days ago get follow-up 2.
Account Health Check
Every 6 hours
Verify Gmail API connectivity for all registered accounts. Mark unhealthy accounts as inactive.
Warmup Increment
Every 24 hours
Increase daily send limit by +5 (up to configured max). Protects Gmail account reputation during warmup.
External Services
NVIDIA NIM
Llama 3.1 70B for email generation, lead enrichment summarization, reply classification.
Gmail API
OAuth2 send + read. Thread management, inbox polling, health checks. RFC 8058 unsubscribe headers.
Google Sheets
Optional lead import from spreadsheets via service account.
Database (SQLite + WAL)

id, first_name, last_name, email (unique), company_name, website, industry, company_description, key_offering, enriched, status, source, campaign_id (FK)
email_records
id, lead_id (FK), subject, body, email_type (initial/followup_1/followup_2), status (pending/sent/failed/bounced), gmail_account, gmail_message_id, gmail_thread_id, sent_at
replies
id, lead_id (FK), reply_body, classification (interested/not_interested/oOO/unsubscribe/spam), confidence_score, gmail_message_id, gmail_thread_id
campaigns
id, name, status (active/paused/completed), daily_limit, warmup_day, current_daily_limit, total_leads, total_sent, total_replies, total_bounces
email_templates
id, subject_pattern, body_pattern, times_used, reply_count, performance_score (feedback loop for AI generation)
gmail_accounts
id, email (unique), display_name, sends_today, last_send_at, is_active, is_healthy
